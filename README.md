# ThreatLens AI

**Agentic Cybersecurity Investigation & Threat Intelligence Platform**

ThreatLens AI investigates suspicious emails, URLs, IP addresses and network activities using AI-powered analysis, threat intelligence and evidence-based risk assessment.

## Features

- Multi-tool cybersecurity investigation agent
- Tiny Aya integration through Cohere V2
- Email and URL threat classification
- IP and network analysis
- Threat intelligence integrations
- Evidence collection and correlation
- Risk assessment and escalation
- Human review and incident reporting
- PDF report generation
- Agent evaluation framework

## Technology Stack

- Python
- Streamlit
- Tiny Aya
- Cohere V2 API
- Scikit-learn
- SQLite
- Hugging Face

## Important

This is a cybersecurity research and demonstration application. Investigation results require human review and should not be treated as definitive security guarantees.

AgentTune fine-tuning and AuditKIT comparative experiments have not yet been completed.
